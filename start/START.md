# Project start

Fill this in (or let Loop ask you these questions in chat). Keep answers short.
Lines starting with `>` are help text; you can leave them.
Then put this file in an empty project folder and say: **Use Loop for this project.**

Name:
> What is the project called?

For:
> Who will use it?

First release must:
> One sentence: what must the first version do?

Platform:
> web, android, ios, mobile (Android + iPhone, one codebase), desktop, backend, cli, other.
> Several are fine: web, android

Stack: to decide
> For example React, Flutter, Kotlin, FastAPI. "to decide" lets Loop suggest options.

Languages: en
> Comma separated, for example en, ml, hi

Test command:
> Optional. For example npm test, ./gradlew test, pytest

Template page:
> Optional. Your basic page or design to build on: an HTML page, a screenshot,
> a Figma export or a folder. Write its path here, or drop the files into a
> folder named template-page next to this file. Every screen will follow it.

## Features
> One line per feature: Title: step > step > step
> Optional lines under a feature: fails: ..., done when: ..., release: 2
> Release 1 is built first; release 2 and later come after.

- 

## Constraints
> Optional. Rules the product must follow.

- 

## Must not
> Optional. Things the product must never do.
