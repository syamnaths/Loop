# Template page

Put your basic template page here before starting a project: an HTML page
(with its CSS and images), a screenshot, a Figma or PDF export, or a small
starter project.

Copy this folder next to your `START.md` (or into the empty project folder).
`loop-init.mjs` moves it to `design/template-page/` in the new project, and
every screen Loop builds follows its layout, colours, fonts and spacing until
you decide otherwise.

This README is ignored; only your files are used.
